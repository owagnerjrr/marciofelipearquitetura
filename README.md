# Márcio Felipe Arquitetura

Site institucional de arquitetura e interiores, com portfólio, apresentação do escritório, serviços e contatos.

## Estrutura

- `index.html`: página e estilos principais.
- `refinements.css`: ajustes de legibilidade, menu móvel e responsividade.
- `site.js`: menu, animações de entrada e galeria acessível.
- `assets/`: fotografias e imagens locais.

Para visualizar, abra `index.html` ou sirva a pasta com um servidor HTTP estático. Não há instalação de dependências nem etapa de compilação.

## Conteúdo

Esta primeira versão utiliza as fotos, os textos e os contatos presentes na referência fornecida: https://duduwwl.github.io/marcio-felipe-arquitetura/.

## GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/ (root)** e salve.
